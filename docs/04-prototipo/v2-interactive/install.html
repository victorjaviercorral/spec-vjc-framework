How to Install

Elige tu agente de Inteligencia Artificial. Human-AI Copilot no es una librería que se instala con npm, sino un sistema operativo mental para agentes autónomos.

terminal

Para Claude Code (CLI)

1. Añadir reglas al proyecto

Clona o copia la carpeta .agents/ en la raíz de tu proyecto. Asegúrate de incluir los prompts en la configuración de Claude.

2. Inicializar Spec

Arranca Claude Code y ejecuta el comando de triaje para generar la estructura documental base.

claude /spec-init

3. Flujo Determinista

Sigue el flujo de comandos para expandir los requisitos y construir el PRD y la especificación técnica.

# Multiplicador de requisitos (Event Storming)
claude /expand
# Revisión ciega de calidad (Quality Gate)
claude /quality-gate
rocket_launch

Para Google Antigravity

1. Instalar entorno y plugins

Instala Antigravity y asegúrate de añadir el plugin Human-AI-Copilot-Framework a la carpeta de configuración.

agy install

2. Iniciar con Goals

Usa la interfaz interactiva para asignar el objetivo inicial al framework.

/goal usa el skill spec-init para este proyecto
forum

Para ChatGPT / Otras IAs [PENDIENTE]

La integración nativa de comandos (slash commands) no está disponible en interfaces de chat estándar. Actualmente, para usar el Human-AI Copilot en ChatGPT, debes copiar y pegar manualmente el contenido de los prompts y reglas ubicados en la carpeta .agents/rules/ al inicio de cada conversación. Estamos trabajando en una solución más automatizada.
