# Identidad Visual: Spec VJC Framework Showcase

## Personalidad (3 Adjetivos)
1. Potente (Impactante)
2. Interactiva / Didáctica
3. Clara

## Tono y Contraste
- Tono: Inspirado en la estética técnica y limpia de la documentación (ej. `victorjaviercorral.com/tools/docs`), pero elevado a una experiencia más inmersiva.
- Fondo: [ASUMIDO: Oscuro o híbrido oscuro/claro | Para resaltar componentes interactivos y código | Puede ser muy sobrio si no se ejecuta bien].

## Referencias
1. **URL Base:** `https://victorjaviercorral.com/tools/docs` (limpieza, estructura, tipografía técnica).
2. **Slides/Presentación:** Concepto de "Storytelling" visual. Queremos transformar la presentación PDF adjunta en una experiencia interactiva en la web (scroll-driven o módulos de explicación lógica).

## Qué Evitar
- Páginas estáticas aburridas de puro texto.
- Componentes genéricos sin motion o interactividad.
- Elementos que requieran backend (formularios complejos, logins). Todo debe ser frontend y links a GitHub/LinkedIn.
